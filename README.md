# ThumbCode (web)

Static site: index.html + manifest + icon. No build step.

## Deploy
- Vercel: vercel.com -> Add New -> Project -> import the repo (or drag this folder with the CLI: `npx vercel --prod`). Framework preset "Other", no build command.
- GitHub Pages: push these files to a repo, Settings -> Pages -> Deploy from branch (main, root).

## Use
Open on your phone, tap the full-screen button (top right). On Android Chrome it also locks to landscape.
iPhone Safari cannot full-screen a page: use Share -> Add to Home Screen instead.
Run server: https://ce.judge0.com by default, change under the gear icon.
